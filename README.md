## Описание

Выполнение лабораторной работы № 6 «Веб-программирование на Python».

Цель — научиться создавать веб-приложения Flask, использовать маршруты, HTML-шаблоны, CSS, формы, базу данных SQLite и загрузку файлов.

Вариант 1: средняя сложность — задания **1, 3, 5**; повышенная сложность — задания **1, 4**.

Каждое задание запускается отдельным Python-файлом. Функция `create_app()` создаёт приложение, `main()` запускает локальный сервер. Защита `if __name__ == "__main__"` не позволяет запускать сервер при импорте модуля.

## Требования и проверка стиля

Python 3.9 или выше. Установите Flask и линтер:

```bash
python -m pip install Flask==3.1.2 flake8==7.3.0
python -m flake8 .
```

SQLite входит в стандартную библиотеку Python. Werkzeug и Jinja устанавливаются вместе с Flask. Виртуальное окружение и requirements.txt в этой работе не используются.

Подключите Git-хук из папки репозитория:

```bash
git config core.hooksPath hooks
chmod +x hooks/pre-commit
```

В Windows команды выполняются в Git Bash. Хук проверяет все Python-файлы рабочей папки и отменяет коммит при ошибках flake8.

## Запуск

Запустите нужный Python-файл и откройте адрес, указанный в описании задания. Сервер занимает терминал, пока работает; для остановки нажмите `Ctrl+C`.

Каждое приложение использует свой порт и привязано к `127.0.0.1`. Режим отладки выключен. Встроенный сервер предназначен для локального обучения, а не для публикации в интернете. Авторизация пользователей в этой работе не реализуется.

## Выполненные задания

### Средн.1 — задание 1: Flask-приложение Hello World

Файл `hello_flask.py`. Маршрут `GET /` возвращает строку `Hello World!`. Декоратор `@app.get()` связывает URL с функцией обработки запроса.

```bash
python hello_flask.py
```

Адрес: http://127.0.0.1:5001/ . В браузере должно появиться приветствие.

### Средн.2 — задание 3: статическая страница и CSS

Файл `static_page.py`. Приложение возвращает страницу `templates/styled_page.html`, которая наследует общий шаблон `templates/base.html`. Оформление вынесено в `static/style.css` и подключено через `url_for('static', ...)`.

Содержимое страницы фиксированное: оно не зависит от формы или базы данных. CSS задаёт шрифт, цвета, отступы, границы и адаптацию к ширине окна.

```bash
python static_page.py
```

Адрес: http://127.0.0.1:5002/ . Проверьте оформление и изменение ширины страницы.

### Средн.3 — задание 5: страница с Bootstrap

Файл `bootstrap_page.py` и шаблон `templates/bootstrap_page.html`. Страница использует Bootstrap 5.3.3: контейнер, адаптивную сетку, карточки, уведомление и кнопку-ссылку.

Оригинальный файл Bootstrap находится в `static/bootstrap.min.css`, лицензия MIT — в `licenses/Bootstrap-LICENSE.txt`. Это сторонний CSS-фреймворк. Стили включены локально, поэтому для просмотра страницы интернет не требуется. JavaScript-компоненты не используются.

```bash
python bootstrap_page.py
```

Адрес: http://127.0.0.1:5003/ . На широком экране карточки расположены в ряд, на узком — друг под другом.
